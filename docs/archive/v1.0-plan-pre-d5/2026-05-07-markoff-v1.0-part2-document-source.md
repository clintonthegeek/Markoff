# Markoff v1.0 — Part 2: Document API + Source Widget

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans`. Steps use checkbox (`- [ ]`) syntax. Read [the overview](2026-05-07-markoff-v1.0-overview.md) first. Part 1 must be landed before starting Part 2.

**Goal:** Reshape `MarkoffDocument`'s consumer-facing signal surface (drop `contentsChanged(o,r,i)`, add `documentChanged()`); add the targeted block-update signals that Part 3's perf work will subscribe to (additive; no breakage); migrate `Markoff::Source::Editor` to inherit `Markoff::MarkdownView`.

**Architecture (this part):** `MarkoffDocument` gains two notification surfaces: (a) the consumer-facing no-arg `documentChanged()` for dirty tracking; (b) the targeted-update signals `blocksChanged(QList<BlockId>)`, `blockInserted(BlockId, int row)`, `blockRemoved(BlockId, int row)` for the live binding to subscribe to in Part 3. `Source::Editor` inherits `MarkdownView` and implements every base virtual.

**End state:** Document signal contract matches v1.0 spec. Source widget conforms to base class. New tests for both. Live widget is not yet using the new signals (Part 3).

**Spec:** §4.2, §4.6, Appendix A of `docs/specs/2026-05-07-markoff-v1.0-design.md`.

#include <QTest>
#include <QSignalSpy>
#include <markoff/core/MarkoffDocument.h>

class TestTargetedBlockSignals : public QObject {
    Q_OBJECT
private slots:
    void edit_emits_blocksChanged_with_touched_id() {
        Markoff::MarkoffDocument doc;
        doc.loadFromMarkdown(QStringLiteral("# Hello\n\nWorld\n"));
        QSignalSpy changed(&doc, SIGNAL(blocksChanged(QList<Markoff::Core::BlockId>)));

        // Apply a buffer edit to the second block (paragraph "World").
        // The actual API is the per-block buffer edit primitive
        // (Cmd::applyBufferEdit / d2ApplyBufferEdit). Use whichever the
        // foundation-exploration tree exposes; the existing live-render
        // tests demonstrate the call shape.
        const auto blockIds = doc.iterateBlocks();
        QVERIFY(blockIds.size() >= 2);
        const auto target = blockIds[1];
        doc.d2ApplyBufferEdit(target, /*offset=*/5, /*removed=*/0,
                              QStringLiteral("!").toUtf8());

        QCOMPARE(changed.count(), 1);
        const auto args = changed.takeFirst();
        const auto ids = args.at(0).value<QList<Markoff::Core::BlockId>>();
        QCOMPARE(ids.size(), 1);
        QCOMPARE(ids[0], target);
    }
    void structural_insert_emits_blockInserted() {
        Markoff::MarkoffDocument doc;
        doc.loadFromMarkdown(QStringLiteral("# A\n"));
        QSignalSpy inserted(&doc, SIGNAL(blockInserted(Markoff::Core::BlockId, int)));

        // Insert a new paragraph after the heading.
        // Use the structural command path; the test asserts the signal
        // is emitted exactly once with the new BlockId and a row index.
        doc.applyFlatEdit(QStringLiteral("# A\n\nB\n"));
        QVERIFY(inserted.count() >= 1);
    }
    void structural_remove_emits_blockRemoved() {
        Markoff::MarkoffDocument doc;
        doc.loadFromMarkdown(QStringLiteral("# A\n\nB\n"));
        QSignalSpy removed(&doc, SIGNAL(blockRemoved(Markoff::Core::BlockId, int)));

        // Remove the paragraph by reducing the buffer.
        doc.applyFlatEdit(QStringLiteral("# A\n"));
        QVERIFY(removed.count() >= 1);
    }
};

- [ ] **Step 5: Reshape impl**

In `libs/markoff-source/src/Editor.cpp`, the constructor builds a `QVBoxLayout` containing a `QPlainTextEdit` and any find/replace bars. All the previous `QPlainTextEdit` direct calls now go through `m_editor->...`.

The `setDocument` override translates `MarkoffDocument*` to the inner editor: install a connection from `MarkoffDocument::documentReloaded` to a slot that calls `m_editor->setPlainText(doc->toMarkdown())`, and from the editor's `textChanged` to a slot that calls `doc->applyFlatEdit(m_editor->toPlainText())`.

```cpp
// libs/markoff-source/src/Editor.cpp
// SPDX-License-Identifier: GPL-3.0-or-later
#include <markoff/source/Editor.h>
#include <markoff/core/MarkoffDocument.h>
#include <QVBoxLayout>

namespace Markoff::Source {

Editor::Editor(QWidget* parent)
    : MarkdownView(parent),
      m_editor(new QPlainTextEdit(this))
{
    auto* layout = new QVBoxLayout(this);
    layout->setContentsMargins(0, 0, 0, 0);
    layout->addWidget(m_editor);

    connect(m_editor, &QPlainTextEdit::textChanged, this, [this]{
        auto* doc = document();
        if (!doc) return;
        if (m_suppressEdit) return;     // re-entry guard during programmatic load
        doc->applyFlatEdit(m_editor->toPlainText());
    });
}

Editor::~Editor() = default;

void Editor::setDocument(Markoff::MarkoffDocument* doc) {
    if (auto* prev = document()) disconnect(prev, nullptr, this, nullptr);
    Markoff::MarkdownView::setDocument(doc);
    if (doc) {
        m_suppressEdit = true;
        m_editor->setPlainText(doc->toMarkdown());
        m_suppressEdit = false;
        connect(doc, &Markoff::MarkoffDocument::documentReloaded, this, [this, doc]{
            m_suppressEdit = true;
            m_editor->setPlainText(doc->toMarkdown());
            m_suppressEdit = false;
        });
    }
}

Markoff::CursorPos Editor::cursorPosition() const {
    auto cursor = m_editor->textCursor();
    return { cursor.blockNumber() + 1, cursor.positionInBlock() + 1 };
}
void Editor::setCursorPosition(Markoff::CursorPos pos) {
    auto block = m_editor->document()->findBlockByNumber(pos.line - 1);
    QTextCursor cursor(block);
    cursor.setPosition(block.position() + pos.column - 1);
    m_editor->setTextCursor(cursor);
}

float Editor::scrollPositionVisualLine() const {
    auto* sb = m_editor->verticalScrollBar();
    if (!sb || sb->maximum() == 0) return 0.0f;
    return static_cast<float>(sb->value()) / static_cast<float>(sb->maximum());
}
void Editor::setScrollPositionVisualLine(float pos) {
    auto* sb = m_editor->verticalScrollBar();
    if (!sb || sb->maximum() == 0) return;
    sb->setValue(static_cast<int>(pos * sb->maximum()));
}

void Editor::setReadOnly(bool ro) {
    Markoff::MarkdownView::setReadOnly(ro);
    m_editor->setReadOnly(ro);
}
bool Editor::isReadOnly() const { return m_editor->isReadOnly(); }

void Editor::showFindBar()    { /* TODO Phase-1.1 in v1.1 — wire find bar */ }
void Editor::showReplaceBar() { /* same */ }
void Editor::hideFindBar()    { /* same */ }

void Editor::setViewTheme(const Markoff::Theme& /*theme*/) {
    // Apply theme to the inner editor — colours, font family, font size.
    // Specific implementation depends on the existing Theme shape; preserve
    // whatever the v0.x Source::Editor did here.
}

} // namespace Markoff::Source
```
