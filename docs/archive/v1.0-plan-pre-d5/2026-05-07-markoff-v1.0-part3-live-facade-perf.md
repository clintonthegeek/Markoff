# Markoff v1.0 — Part 3: Live Facade and Perf

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans`. Read [the overview](2026-05-07-markoff-v1.0-overview.md) first. Parts 1 and 2 must be landed before starting Part 3.

**Goal:** Build the `Markoff::Live::Editor` QWidget facade hosting the QML scene; replace the per-keystroke full-document walk in `LiveListModelBinding` with a targeted handler driven by the new `MarkoffDocument` block-update signals; defer document load until after first paint; make image decode asynchronous; add a perf benchmark that gates the v1.0 floor (≤500 ms / ≤300 MB / ≤2 % idle CPU on a 500-line document).

**Architecture (this part):** `Live::Editor` is a `QWidget` containing a `QQuickWidget` child whose root is the existing `LiveView.qml` (loaded as a Qt resource compiled into `markoff-live`). C++ classes (`LiveListModelBinding`, `LiveCursorState`, etc.) are exposed via `setContextProperty`. The facade inherits `Markoff::MarkdownView` and implements every base virtual. Perf comes from replacing `LiveListModelBinding::onD2Changed`'s full-walk with a handler on the new `MarkoffDocument::blocksChanged / blockInserted / blockRemoved` signals (added in Part 2 Phase 2), moving kind-transition out of the hot path, removing the unused per-block `inlineSpansFor` call, deferring the document load to `QTimer::singleShot(0, ...)`, and setting `Image { asynchronous: true }` in the image delegate.

**End state:** Live widget hosted as a QWidget. Perf benchmark passes. Reading mode is `Live::Editor` constructed with `setReadOnly(true)`.

**Spec:** §4.3, §4.4, §5 of `docs/specs/2026-05-07-markoff-v1.0-design.md`.

```cpp
// Replace the existing connect in setDocument():
void LiveListModelBinding::setDocument(Markoff::MarkoffDocument* doc) {
    if (d->document) {
        disconnect(d->document, nullptr, this, nullptr);
    }
    d->document = doc;
    if (!doc) {
        d->model->clear();
        return;
    }
    // Initial population: do the full walk ONCE, on document attach. Per-edit
    // changes are handled by the targeted slots below.
    rebuildAllBlocks();
    connect(doc, &Markoff::MarkoffDocument::blocksChanged,
            this, &LiveListModelBinding::onBlocksChanged);
    connect(doc, &Markoff::MarkoffDocument::blockInserted,
            this, &LiveListModelBinding::onBlockInserted);
    connect(doc, &Markoff::MarkoffDocument::blockRemoved,
            this, &LiveListModelBinding::onBlockRemoved);
    connect(doc, &Markoff::MarkoffDocument::documentReloaded,
            this, &LiveListModelBinding::onDocumentReloaded);
}

void LiveListModelBinding::onBlocksChanged(QList<Markoff::Core::BlockId> ids) {
    auto* doc = d->document;
    if (!doc) return;
    for (const auto& id : ids) {
        const int row = d->model->rowOf(id);
        if (row < 0) continue;
        BlockRecord r = extractBlockRecord(doc, id);    // helper, see below
        d->model->updateRow(row, std::move(r));
        // model->updateRow emits dataChanged(index(row), index(row)).
    }
    // No documentChanged emit here; the document already emitted it.
}

void LiveListModelBinding::onBlockInserted(Markoff::Core::BlockId id, int row) {
    auto* doc = d->document;
    if (!doc) return;
    BlockRecord r = extractBlockRecord(doc, id);
    d->model->insertRow(row, std::move(r));
}

void LiveListModelBinding::onBlockRemoved(Markoff::Core::BlockId /*id*/, int row) {
    d->model->removeRow(row);
}

void LiveListModelBinding::onDocumentReloaded() {
    rebuildAllBlocks();    // single full-walk on full content swap; this is the only place that runs the legacy path.
}

// Helper: extracts a BlockRecord. Note: NO inlineSpansFor() call (Phase 5 drops that).
BlockRecord LiveListModelBinding::extractBlockRecord(Markoff::MarkoffDocument* doc,
                                                     Markoff::Core::BlockId id) {
    BlockRecord r;
    r.blockAnchor = id;
    r.kind        = blockKindToString(doc->blockKind(id));
    QByteArray raw = doc->blockText(id);
    if (raw.endsWith('\n')) raw.chop(1);
    r.text  = QString::fromUtf8(raw);
    r.attrs = doc->blockAttrs(id);
    // Kind-specific extraction (heading level, code language, list metadata)
    // stays the same as the legacy onD2Changed; copy that block of code here.
    return r;
}

void LiveListModelBinding::rebuildAllBlocks() {
    auto* doc = d->document;
    if (!doc) return;
    const auto blockIds = doc->iterateBlocks();
    QList<BlockRecord> records;
    records.reserve(static_cast<int>(blockIds.size()));
    for (const auto& id : blockIds) {
        records.append(extractBlockRecord(doc, id));
    }
    d->model->resetTo(std::move(records));
}
```

## Phase 4 — Move kind-transition out of the hot path

### Task 4.1: Run kind inference only on touched blocks crossing a kind boundary

The legacy `onD2Changed` ran kind inference on every Equal-op block on every change. ```cpp
// Returns true if `text` likely changes kind compared to currentKind.
// Cheap heuristic: leading-character markers for headings, lists, blockquotes,
// code fences, hr, and table pipes. If false, skip inferBlockKind and Cmd::changeKind.
static bool textMayCrossKindBoundary(const QString& text, const QString& currentKind) {
    if (text.isEmpty()) return currentKind != Markoff::BlockKindNames::Paragraph;
    const QChar c0 = text.at(0);
    const bool startsLikeHeading   = c0 == QChar('#');
    const bool startsLikeList      = c0 == QChar('-') || c0 == QChar('*') || c0 == QChar('+');
    const bool startsLikeQuote     = c0 == QChar('>');
    const bool startsLikeCodeFence = text.startsWith("```");
    const bool startsLikeHr        = text.startsWith("---") || text.startsWith("***");
    const bool startsLikeMath      = text.startsWith("$$");
    const bool kindIsParagraph     = currentKind == Markoff::BlockKindNames::Paragraph;

    if (startsLikeHeading   && currentKind != Markoff::BlockKindNames::Heading)        return true;
    if (startsLikeList      && currentKind != Markoff::BlockKindNames::ListItem)       return true;
    if (startsLikeQuote     && currentKind != Markoff::BlockKindNames::Blockquote)     return true;
    if (startsLikeCodeFence && currentKind != Markoff::BlockKindNames::CodeBlock)      return true;
    if (startsLikeHr        && currentKind != Markoff::BlockKindNames::HorizontalRule) return true;
    if (startsLikeMath      && currentKind != Markoff::BlockKindNames::Math)           return true;
    // Reverse cases: previously a non-paragraph kind, now plain text → may revert.
    if (!startsLikeHeading && !startsLikeList && !startsLikeQuote &&
        !startsLikeCodeFence && !startsLikeHr && !startsLikeMath && !kindIsParagraph) return true;
    return false;
}

```cpp
void LiveListModelBinding::onBlocksChanged(QList<Markoff::Core::BlockId> ids) {
    auto* doc = d->document;
    if (!doc) return;
    for (const auto& id : ids) {
        const int row = d->model->rowOf(id);
        if (row < 0) continue;
        BlockRecord r = extractBlockRecord(doc, id);
        const QString prevKind = d->model->kindAt(row);
        if (textMayCrossKindBoundary(r.text, prevKind)) {
            const QString inferred = inferBlockKind(r.text, /*displayMode*/nullptr);
            if (inferred != prevKind) {
                Markoff::Core::Cmd::changeKind(*doc, id, inferred);
                // changeKind triggers another blocksChanged(id); that next pass
                // will see the kind already matches and not recurse.
                continue;
            }
        }
        d->model->updateRow(row, std::move(r));
    }
}
```

## Phase 6 — Async startup + asynchronous Image

### Task 6.1: Defer document load to first-paint

**Files:**
- Modify: `libs/markoff-live/src/Editor.cpp` (the facade)

- [ ] **Step 1: Inspect current load sequence**

The legacy demo (`libs/markoff-live/app/main.cpp`) calls `doc->loadFromMarkdown(content)` synchronously before showing the window. The facade so far loads the document via `setDocument` whenever the host calls it — usually *also* synchronously.

Inside the facade, defer the *first* `setDocument` rebuild until after the QQuickWidget has rendered its first frame. This is the cheapest deferral: `QTimer::singleShot(0, ...)` posts to the next event-loop turn, by which point the window is shown.

- [ ] **Step 2: Modify `setDocument` to defer the initial rebuild**

```cpp
void Editor::setDocument(Markoff::MarkoffDocument* doc) {
    Markoff::MarkdownView::setDocument(doc);
    m_cursor->setDocument(doc);
    if (!isVisible()) {
        // Initial attach before show: defer the rebuild until first event-loop turn.
        QTimer::singleShot(0, this, [this, doc]{
            m_binding->setDocument(doc);
        });
    } else {
        m_binding->setDocument(doc);
    }
}
```

The host typically calls `setDocument` before `show()`; the deferral ensures the window is up by the time the binding rebuilds.

```cpp
// SPDX-License-Identifier: GPL-3.0-or-later
#include <QTest>
#include <QFile>
#include <QElapsedTimer>
#include <markoff/live/Editor.h>
#include <markoff/core/MarkoffDocument.h>
#include <chrono>

#ifdef Q_OS_LINUX
#include <sys/resource.h>
static long peakRssKB() {
    struct rusage ru{};
    getrusage(RUSAGE_SELF, &ru);
    return ru.ru_maxrss;
}
#else
static long peakRssKB() { return 0; }
#endif

class TestV10Perf500Line : public QObject {
    Q_OBJECT
private slots:
    void load_under_500ms_under_300mb() {
        QFile f(QStringLiteral(":/perf/500-line.md"));
        if (!f.open(QIODevice::ReadOnly)) {
            f.setFileName(QStringLiteral(SOURCE_DIR "/tests/perf/data/500-line.md"));
            QVERIFY(f.open(QIODevice::ReadOnly));
        }
        const QString content = QString::fromUtf8(f.readAll());

        Markoff::MarkoffDocument doc;
        doc.loadFromMarkdown(content);

        QElapsedTimer t;
        t.start();
        Markoff::Live::Editor editor;
        editor.setDocument(&doc);
        editor.show();
        // Pump events until the QQuickWidget reports its first frame.
        // Cheapest proxy: spin the event loop for up to 1 second waiting
        // for editor->isVisible() to be true and a single QML frame to render.
        QTest::qWaitForWindowExposed(&editor, 1000);
        const qint64 ms = t.elapsed();

        QVERIFY2(ms <= 500, qPrintable(QStringLiteral("first-frame ms = %1 (target ≤ 500)").arg(ms)));

#ifdef Q_OS_LINUX
        const long rssKB = peakRssKB();
        QVERIFY2(rssKB <= 300L * 1024L,
                 qPrintable(QStringLiteral("peak RSS = %1 KB (target ≤ 307200)").arg(rssKB)));
#endif
    }
    void idle_cpu_under_2pct_between_keystrokes() {
        // Sample CPU load by counting wall-clock vs CPU time over a 500ms idle period
        // after rendering. Rough heuristic; not flake-proof but catches a regression.
        QFile f(QStringLiteral(SOURCE_DIR "/tests/perf/data/500-line.md"));
        QVERIFY(f.open(QIODevice::ReadOnly));
        const QString content = QString::fromUtf8(f.readAll());

        Markoff::MarkoffDocument doc;
        doc.loadFromMarkdown(content);
        Markoff::Live::Editor editor;
        editor.setDocument(&doc);
        editor.show();
        QTest::qWaitForWindowExposed(&editor, 2000);

#ifdef Q_OS_LINUX
        struct rusage before{}, after{};
        getrusage(RUSAGE_SELF, &before);
        QTest::qWait(500);
        getrusage(RUSAGE_SELF, &after);
        const auto userMs = ((after.ru_utime.tv_sec  - before.ru_utime.tv_sec)  * 1000)
                          + ((after.ru_utime.tv_usec - before.ru_utime.tv_usec) / 1000);
        const auto sysMs  = ((after.ru_stime.tv_sec  - before.ru_stime.tv_sec)  * 1000)
                          + ((after.ru_stime.tv_usec - before.ru_stime.tv_usec) / 1000);
        const auto cpuMs  = userMs + sysMs;
        // Target: ≤ 2% over a 500ms wall window = ≤ 10ms CPU.
        QVERIFY2(cpuMs <= 50,    // generous threshold for CI flake; real budget is 10ms

    }
```
