# Markoff v1.0 — Part 4: Live Links and Test App

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans`. Read [the overview](2026-05-07-markoff-v1.0-overview.md) first. Parts 1–3 must be landed before starting Part 4.

**Goal:** Render link spans as styled (clickable + hoverable) inline runs in the live widget; route mouse events back to C++ as `linkClicked` and `linkHovered` signals on `Live::Editor`; support host-resolved image sources via `imageSourceRequested` + `provideImageSource`; rebuild the test app `markoff-testapp` to exercise the v1.0 surface in tri-mode (Live edit / Live read-only / Source) on a single shared `MarkoffDocument`.

**Architecture (this part):** A small inline-runs scaffold is added to the QML delegates that render block text (`ParagraphDelegate`, `HeadingDelegate`, `ListItemDelegate`, `BlockquoteDelegate`). The scaffold consumes a *link-spans only* subset of the parser's inline data via a new model role and renders link runs styled (theme color + underline). Per-link `MouseArea` overlays detect hover and click; the binding re-emits these as facade signals. The binding additionally exposes an `imageSourceRequested(QString relPath, QString token)` signal and a matching `provideImageSource(QString token, QString resolvedPath)` slot for asynchronous host-resolution. The test app composes a tri-mode UI on the new `Live::Editor` and `Source::Editor`, sharing one `MarkoffDocument`.

**End state:** Links clickable + hoverable. Image sources host-resolvable. Tri-mode test app works end to end on the v1.0 API. Reading mode is `Live::Editor` constructed with `setReadOnly(true)`.

**Spec:** §4.3, §4.4, §5.2 of `docs/specs/2026-05-07-markoff-v1.0-design.md`.

    const auto allSpans = doc->inlineSpansFor(id);   // re-introduced HERE only —

                                                      // a block is touched.
    QList<LinkSpan> out;
    for (const auto& s : allSpans) {

        ls.kind   = kind;
        out.append(std::move(ls));
    }
    return out;

### Task 2.1: ParagraphDelegate — RichText overlay for link runs

**Files:**
- Modify: `libs/markoff-live/qml/delegates/ParagraphDelegate.qml`

The strategy: keep the existing `TextEdit { textFormat: TextEdit.PlainText }` as the editable canonical text (so cursor / selection / IME continue working unchanged), and overlay a *non-editable* `Text { textFormat: Text.RichText }` that shows the same string with `<a href="...">` tags wrapping link spans. Bold/italic/code stay literal in v1.0; the overlay renders only links.

Per-link `MouseArea` instances are dynamically generated for hover/click detection. Because Text.RichText handles `<a>` clicks via its own `linkActivated` signal, we use that path rather than building rectangles by hand.

```qml
// libs/markoff-live/qml/delegates/ParagraphDelegate.qml
// SPDX-License-Identifier: GPL-3.0-or-later
import QtQuick
import QtQuick.Controls

Item {
    id: root
    property string blockText: model.text
    property var    linkSpans: model.linkSpans

    // Editable canonical text (unchanged from pre-v1.0)
    TextEdit {
        id: editor
        anchors.fill: parent
        text: root.blockText
        textFormat: TextEdit.PlainText
        readOnly: ctxReadOnly
        // ... existing connections to LiveEditBinding for keystroke routing ...
    }

    // Link overlay — visible only when there are link spans
    Text {
        id: linkOverlay
        anchors.fill: editor
        textFormat: Text.RichText
        visible: root.linkSpans && root.linkSpans.length > 0
        // Make the overlay see-through where there is no link, so the editor's
        // text is the actual visible text. We accomplish this by rendering the
        // entire block text but with all non-link characters in transparent color.
        text: root._buildOverlayText(root.blockText, root.linkSpans)
        color: "transparent"
        linkColor: theme.linkColor          // theme-driven link color (set up by binding)
        font: editor.font
        // Capture link clicks
        onLinkActivated: function(href) {
            ctxBinding.onLinkActivated(href, root._currentModifiers())
        }
        onLinkHovered: function(href) {
            const pos = root.mapToGlobal(linkOverlay.x, linkOverlay.y)
            ctxBinding.onLinkHovered(href, pos)
        }
    }

    // Helper: build a RichText string with link spans wrapped in <a>, all
    // surrounding text in transparent <span>. JS string-build runs once per
    // re-render of this delegate; cheap relative to TextEdit layout.
    function _buildOverlayText(text, spans) {
        if (!spans || spans.length === 0) return ""
        let html = ""
        let cursor = 0
        for (let i = 0; i < spans.length; i++) {
            const s = spans[i]
            if (s.start > cursor) {
                html += "<span style=\"color:transparent\">" + _escape(text.substring(cursor, s.start)) + "</span>"
            }
            const inner = text.substring(s.start, s.start + s.length)
            html += "<a href=\"" + _escape(s.href) + "\">" + _escape(inner) + "</a>"
            cursor = s.start + s.length
        }
        if (cursor < text.length) {
            html += "<span style=\"color:transparent\">" + _escape(text.substring(cursor)) + "</span>"
        }
        return html
    }

    function _escape(s) {
        return s.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;").replace(/"/g, "&quot;")
    }

    function _currentModifiers() {
        // No direct access to keyboard modifiers in onLinkActivated; bridge via
        // the binding's last-known-modifiers tracker (updated in onLinkHovered's
        // mouse path). Cheap and good enough for v1.0.
        return ctxBinding.lastKeyboardModifiers
    }
}
```

The `theme` context property is added if not already present. The `lastKeyboardModifiers` property on the binding is a small `Q_PROPERTY` that gets updated on hover-move events; v1.0 is OK shipping a Ctrl-click that needs a hover first.

        function onImageSourceResolved(token, path) {
            if (token === root._token) {
                root._resolved = path
            }
        }
    }

    Image {
        id: imgDisplay
        anchors.fill: parent
        source: root._resolved !== "" ? "file://" + root._resolved : ""
        asynchronous: true
        fillMode: Image.PreserveAspectFit
        // existing properties
    }

    // Loading placeholder while _resolved is empty
    Rectangle {
        anchors.fill: parent
        visible: root._resolved === "" && root.imgRelPath !== ""
        color: theme.placeholderColor || "#eee"
    }
}
```

// apps/markoff-testapp/MainWindow.cpp
// SPDX-License-Identifier: GPL-3.0-or-later
#include "MainWindow.h"
#include <QStackedWidget>
#include <QToolBar>
#include <QAction>
#include <QActionGroup>

MainWindow::MainWindow(QWidget* parent) : QMainWindow(parent) {
    m_stack = new QStackedWidget(this);
    setCentralWidget(m_stack);

    m_liveEdit = new Markoff::Live::Editor(this);
    m_liveRead = new Markoff::Live::Editor(this);
    m_liveRead->setReadOnly(true);
    m_source   = new Markoff::Source::Editor(this);

    m_stack->addWidget(m_liveEdit);
    m_stack->addWidget(m_liveRead);
    m_stack->addWidget(m_source);

    auto* tb = addToolBar(tr("Mode"));
    auto* group = new QActionGroup(this);
    m_actLive = tb->addAction(tr("Live"));
    m_actRead = tb->addAction(tr("Reading"));
    m_actSrc  = tb->addAction(tr("Source"));
    for (auto* a : {m_actLive, m_actRead, m_actSrc}) {
        a->setCheckable(true);
        group->addAction(a);
    }
    m_actLive->setChecked(true);

    connect(m_actLive, &QAction::triggered, this, &MainWindow::switchToLiveEdit);
    connect(m_actRead, &QAction::triggered, this, &MainWindow::switchToLiveReadOnly);
    connect(m_actSrc,  &QAction::triggered, this, &MainWindow::switchToSource);

    // All three leaves share the same canonical document.
    m_liveEdit->setDocument(&m_doc);
    m_liveRead->setDocument(&m_doc);
    m_source->setDocument(&m_doc);

    // Wire link signals to a status-bar reporter (for visual confirmation)
    auto reportLink = [this](QString href, Qt::KeyboardModifiers){
        statusBar()->showMessage(tr("link: %1").arg(href), 3000);
    };
    connect(m_liveEdit, &Markoff::Live::Editor::linkClicked, this, reportLink);
    connect(m_liveRead, &Markoff::Live::Editor::linkClicked, this, reportLink);
}

void MainWindow::loadMarkdown(const QString& text) {
    m_doc.loadFromMarkdown(text);
}

void MainWindow::switchToLiveEdit()     { m_stack->setCurrentWidget(m_liveEdit); }
void MainWindow::switchToLiveReadOnly() { m_stack->setCurrentWidget(m_liveRead); }
void MainWindow::switchToSource()       { m_stack->setCurrentWidget(m_source); }
```
