# E2.6 dogfood request

**Date:** 2026-05-10
**Status:** Implementation complete; pending interactive sign-off.
**Branch:** `exploration/new-foundation`. Worktree: `.worktrees/foundation-exploration/`.

## What to verify

Open a representative `.md` containing H1–H6, paragraphs, blockquote,
code block, list, math, image. Then walk through:

1. **Baseline render at scale 1.0.** Body lands ≈ 14 px; H1 ≈ 25.2 px;
   H2 ≈ 21 px; H3 ≈ 18.2 px; H4 ≈ 16.1 px; H5 ≈ 14.7 px; H6 ≈ 14 px;
   blockquote 14 px italic; code-block 13 px monospace. Sizes are
   slightly smaller than pre-E2.6 (28/24/20/18/16/14 → multiplier
   table); record any visual pushback.
2. **Zoom in (Ctrl+= / Ctrl++).** All text grows uniformly. ListView
   keeps approximate scroll position (any drop = file Live-side bug
   before tag).
3. **Zoom out (Ctrl+-).** Symmetric.
4. **Reset (Ctrl+0).** Snaps back to scale 1.0.
5. **Wheel zoom (Ctrl + scroll wheel).** Smooth multi-step.
6. **Light/dark toggle (Ctrl+Shift+D).** Colours swap; cursor
   preserved; inline-highlighter formats re-render.
7. **Inline-code zoom.** A `` `inline code` `` span inside a
   paragraph scales with zoom (it would not have, pre-Phase-3).

## What to file as a bug (block tag)

- Scroll-position loss on zoom.
- Inline-highlighter re-render desync (e.g., bold delimiters wrong
  size after zoom).
- Theme toggle leaving cursor in a broken focus state.
- Anything that breaks the existing 190-test guarantee on a smaller
  sample (re-run tests if suspicious).
