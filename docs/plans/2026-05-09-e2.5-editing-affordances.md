# E2.5 — Editing affordances pack — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Markoff Live from "you can type into it" to "you can use it as an editor" — Cut/Copy/Paste with hybrid flat / structure-aware paths, a per-binding `QAction` collection consumed by menus and toolbars, right-click context menu, format toggles (Ctrl+B/I/K), save/dirty/window-title for `markoff-live-app`, Live-side `Session` subscription, and verified empty-doc behavior.

## Plan-time resolutions of spec §13 open questions

- **Bulk-paste perf gate:** measure at 100 / 500 / 1000 / 5000 blocks in Task I1. If 1000-block paste exceeds 200 ms wall-clock, take the `beginBulkApply()` / `endBulkApply()` mitigation path in Task I2.
- **macOS modified-state indicator:** ship `*` in the title on all platforms (uniform behavior, no platform branch). Future polish task can wire macOS-native if needed.
- **`saveRequested()` signal vs callback:** Qt-signal. Hosts connect a slot; matches every other controller's idiom in this codebase.
- **`LiveListModelBinding::Capabilities` flag shape:** simple bitmask (`Capabilities::Clipboard | Format | Actions | Session`). Default in ctor is `All`. Plan does not exercise non-default values; that is E6 distillation work.
- **Recent-cuts cache size:** 8 entries (each holds `{cutSeq, vector<BlockId>}`, ~256 bytes worst case; ageing by FIFO).

void MarkoffDocument::recordRecentCut(quint64 cutSeq, std::vector<Markoff::BlockId> ids) {
    d->recentCuts.push_back({cutSeq, std::move(ids)});
    while (d->recentCuts.size() > Private::kRecentCutsMax)
        d->recentCuts.pop_front();
}

std::vector<Markoff::BlockId> MarkoffDocument::takeRecentCut(quint64 cutSeq) {
    for (auto it = d->recentCuts.begin(); it != d->recentCuts.end(); ++it) {
        if (it->cutSeq == cutSeq) {
            auto ids = std::move(it->blockIds);
            d->recentCuts.erase(it);
            return ids;
        }
    }
    return {};
}
```

- [ ] **Step 4: Implement**

```cpp
void MarkoffDocument::applyStructuredPaste(const Markoff::Selection &replaceRange,
                                           const QJsonArray &blocks,
                                           const Markoff::PasteMeta &meta) {
    // 1. Open an undo transaction.
    auto trans = d->undoLog.beginTransaction();

    // 2. Resolve the replace range to flat byte offsets.
    const quint32 startByte = resolveTextAnchor(replaceRange.anchor);
    const quint32 endByte   = resolveTextAnchor(replaceRange.active);
    const quint32 lo = std::min(startByte, endByte);
    const quint32 hi = std::max(startByte, endByte);

    // 3. Serialize blocks to flat markdown.
    QByteArray flat;
    bool first = true;
    for (const auto &v : blocks) {
        const QJsonObject obj = v.toObject();
        if (!first) flat.append("\n\n");
        first = false;
        const QString kind = obj.value("kind").toString();
        const QString text = obj.value("text").toString();
        if (kind == "Heading") {
            const int level = obj.value("attrs").toObject().value("level").toInt(1);
            flat.append(QByteArray(level, '#'));
            flat.append(' ');
            flat.append(text.toUtf8());
        } else if (kind == "CodeBlock") {
            const QString lang = obj.value("attrs").toObject().value("language").toString();
            flat.append("```");
            flat.append(lang.toUtf8());
            flat.append('\n');
            flat.append(text.toUtf8());
            flat.append("\n```");
        } else if (kind == "ListItem") {
            const QString marker = obj.value("attrs").toObject().value("marker").toString("-");
            flat.append(marker.toUtf8());
            flat.append(' ');
            flat.append(text.toUtf8());
        } else if (kind == "Blockquote") {
            flat.append("> ");
            flat.append(text.toUtf8());
        } else {
            // Paragraph and unknown kinds: raw text.
            flat.append(text.toUtf8());
        }
    }

    // 4. Apply as a flat edit (decomposes to per-block ops, re-derives kinds).
    applyFlatEdit(lo, hi, flat, Markoff::Origin::Local);

    // 5. Reuse cached BlockIds if requested.
    if (meta.reuseBlockIds) {
        auto cached = takeRecentCut(meta.cutSeq);
        if (!cached.empty()) {
            // Walk newly-inserted blocks (the ones whose buffer position
            // falls inside [lo, lo + flat.size())) and remap their IDs.
            // Implementation: see d->idList.replaceRange(...).
            d->idList.replaceRangeWithCachedIds(lo, lo + flat.size(), cached);
        }
    }
    // Transaction commits on dtor.
}

void LiveSelectionView::setSession(Markoff::Session *session) {
    if (m_session == session) return;
    if (m_session)
        QObject::disconnect(m_session, nullptr, this, nullptr);
    m_session = session;
    if (m_session) {
        QObject::connect(m_session,
                         &Markoff::Session::primarySelectionChanged,
                         this,
                         &LiveSelectionView::onSessionPrimarySelectionChanged);
    }

void LiveSelectionView::onSessionPrimarySelectionChanged(const Markoff::Selection &sel) {
    if (m_applyingSessionSelection) return;
    if (!m_document || !m_model) return;

    // Resolve anchors to (blockIndex, qtPos).
    const auto resolve = [&](const Markoff::TextAnchor &a, int &blockIdx, int &qtPos) -> bool {
        const auto blockOpt = m_document->blockAt(a);
        if (!blockOpt) return false;
        const int idx = m_document->blockIndexOf(*blockOpt);  // helper; add if missing
        if (idx < 0) return false;
        const int rowCount = m_model->rowCount();
        if (idx >= rowCount) return false;
        const int byteOff = m_document->offsetInBlock(*blockOpt, a);
        const QByteArray utf8 = m_model->recordAt(idx).text.toUtf8();
        const int clamped = std::clamp(byteOff, 0, static_cast<int>(utf8.size()));
        blockIdx = idx;
        qtPos    = static_cast<int>(Coordinates::byteToQtPos(utf8, clamped));
        return true;
    };

    int ab, ap, xb, xp;
    if (!resolve(sel.anchor, ab, ap) || !resolve(sel.active, xb, xp)) {
        // Orphaned anchor → clear selection.
        clear();
        return;
    }

    m_applyingSessionSelection = true;
    m_anchorBlock = ab; m_anchorQtPos = ap;
    m_activeBlock = xb; m_activeQtPos = xp;
    Q_EMIT selectionChanged();
    m_applyingSessionSelection = false;
}

        if (r.x() < 0) continue;

        obj["kind"] = QString::fromUtf8(rec.kindName);
        obj["text"] = text;
        // Per-kind attrs: minimal here; expand in C3 with kind-specific fields.
        out.append(obj);
    }
    return out;
}

QString joinPlain(const QJsonArray &blocks) {
    QStringList parts;
    for (const auto &v : blocks) parts << v.toObject().value("text").toString();
    return parts.join('\n');
}

void LiveClipboardController::paste() {
    if (!m_selection || !m_document) return;
    const QClipboard *cb = QApplication::clipboard();
    const QMimeData *mime = cb->mimeData();
    if (!mime) return;

    // Compute the replace range from the current selection (or caret).
    int fb = m_selection->anchorBlock(), fo = m_selection->anchorQtPos();
    int lb = m_selection->activeBlock(), lo = m_selection->activeQtPos();
    if (fb < 0 || lb < 0) return;
    if (fb > lb || (fb == lb && fo > lo)) { std::swap(fb, lb); std::swap(fo, lo); }

    const auto byteOf = [&](int blockIdx, int qtPos) -> quint32 {
        const auto &rec = m_model->recordAt(blockIdx);
        const QByteArray utf8 = rec.text.toUtf8();
        const auto blockStart = m_document->blockByteRange(rec.blockAnchor)->first;
        return blockStart + Coordinates::qtPosToByte(utf8, qMax(0, qtPos));
    };
    const quint32 startByte = byteOf(fb, fo);
    const quint32 endByte   = byteOf(lb, lo);

    // Try the structured fast-path.
    if (mime->hasFormat(kBlocksMime)) {
        const auto bytes = mime->data(kBlocksMime);
        const auto json  = QJsonDocument::fromJson(bytes);
        if (json.isObject() && json.object().value("version").toInt() == 1) {
            const auto obj = json.object();
            const QJsonArray blocks = obj.value("blocks").toArray();
            const quint16 sourceReplica =
                static_cast<quint16>(obj.value("sourceReplicaId").toInt(0));

            Markoff::Selection range;
            range.kind   = Markoff::Selection::Kind::Primary;
            range.anchor = m_document->textAnchorAt(startByte, true);
            range.active = m_document->textAnchorAt(endByte, false);

            Markoff::PasteMeta meta;
            if (sourceReplica == m_document->replicaId() &&
                obj.contains("cutSequenceNumber"))
            {
                meta.reuseBlockIds = true;
                meta.cutSeq = static_cast<quint64>(obj.value("cutSequenceNumber").toDouble());
            }
            m_document->applyStructuredPaste(range, blocks, meta);
            m_selection->clear();
            return;
        }
    }

    // Flat fallback.
    if (mime->hasText()) {
        const QByteArray text = mime->text().toUtf8();
        m_document->applyFlatEdit(startByte, endByte, text, Markoff::Origin::Local);
        m_selection->clear();
    }
}

// SPDX-License-Identifier: GPL-3.0-or-later
#include "markoff/live/LiveFormatController.h"

#include <markoff/core/MarkoffDocument.h>
#include <markoff/live/LiveSelectionView.h>
#include <markoff/live/LiveBlockModel.h>

namespace Markoff::Live {

LiveFormatController::LiveFormatController(QObject *parent) : QObject(parent) {}

void LiveFormatController::setDocument(Markoff::MarkoffDocument *doc)  { m_document  = doc; }
void LiveFormatController::setSelectionView(LiveSelectionView *sv)     { m_selection = sv; }
void LiveFormatController::setModel(const LiveBlockModel *m)           { m_model     = m;  }

void LiveFormatController::wrapPerBlock(const QByteArray &openDelim, const QByteArray &closeDelim) {
    if (!m_document || !m_model || !m_selection) return;
    if (!m_selection->hasSelection()) return;

    // Walk per-block from last to first so byte offsets remain valid as we edit.
    const int rowCount = m_model->rowCount();
    QList<int> blockIdxs;
    for (int i = 0; i < rowCount; ++i)
        if (m_selection->rangeForBlock(i).x() >= 0) blockIdxs.append(i);

    auto &log = m_document->d2UndoLog();
    auto trans = log.beginTransaction();

    for (int n = blockIdxs.size() - 1; n >= 0; --n) {
        const int i = blockIdxs[n];
        const QPoint r = m_selection->rangeForBlock(i);
        const auto &rec = m_model->recordAt(i);
        const int qLo = r.x();
        const int qHi = (r.y() == INT_MAX) ? rec.text.length() : r.y();
        if (qHi <= qLo) continue;
        const QByteArray utf8 = rec.text.toUtf8();
        const auto blockStart = m_document->blockByteRange(rec.blockAnchor)->first;
        const quint32 byteLo = blockStart + Coordinates::qtPosToByte(utf8, qLo);
        const quint32 byteHi = blockStart + Coordinates::qtPosToByte(utf8, qHi);

        // Detect existing wrap: text[byteLo..byteLo+open) == openDelim and similarly at end.
        const auto containsExistingWrap = [&]() -> bool {
            if (byteLo < blockStart + (quint32)openDelim.size()) return false;
            const auto pre  = m_document->toMarkdownUtf8().mid(
                static_cast<int>(byteLo - openDelim.size()), openDelim.size());
            const auto post = m_document->toMarkdownUtf8().mid(
                static_cast<int>(byteHi), closeDelim.size());
            return pre == openDelim && post == closeDelim;
        };

        if (containsExistingWrap()) {
            // Unwrap: remove the trailing then leading delimiters.
            m_document->applyFlatEdit(byteHi, byteHi + closeDelim.size(),
                                      QByteArray(), Markoff::Origin::Local);
            m_document->applyFlatEdit(byteLo - openDelim.size(), byteLo,
                                      QByteArray(), Markoff::Origin::Local);
        } else {
            // Wrap: insert closeDelim at end first (preserves byteLo).
            m_document->applyFlatEdit(byteHi, byteHi, closeDelim, Markoff::Origin::Local);
            m_document->applyFlatEdit(byteLo, byteLo, openDelim, Markoff::Origin::Local);
        }
    }
    // Transaction commits on dtor.
}

void LiveFormatController::toggleBold()   { wrapPerBlock("**", "**"); }
void LiveFormatController::toggleItalic() { wrapPerBlock("_",  "_");  }

void LiveFormatController::insertLink() {
    if (!m_document || !m_model || !m_selection) return;

    // Empty selection? Insert "[](url)" at caret with caret inside [].
    if (!m_selection->hasSelection()) {
        // ... look up caret byte; insert "[](url)"; emit cursor-move request.
        // Implementation uses LiveCursorState::requestTextCaretAtRow analogously
        // to LiveStructuralKeyHandler. (Defer to E2's existing cursor-pending pattern.)
        return;
    }

    // Nonempty: wrap selection with "[" + selection + "](url)".
    // Per-block independent.
    if (m_selection->anchorBlock() == m_selection->activeBlock()) {
        const int row = m_selection->anchorBlock();
        const auto &rec = m_model->recordAt(row);
        const QByteArray utf8 = rec.text.toUtf8();
        const auto blockStart = m_document->blockByteRange(rec.blockAnchor)->first;
        int qLo = m_selection->anchorQtPos();
        int qHi = m_selection->activeQtPos();
        if (qLo > qHi) std::swap(qLo, qHi);
        const quint32 byteLo = blockStart + Coordinates::qtPosToByte(utf8, qLo);
        const quint32 byteHi = blockStart + Coordinates::qtPosToByte(utf8, qHi);

        auto &log = m_document->d2UndoLog();
        auto trans = log.beginTransaction();
        m_document->applyFlatEdit(byteHi, byteHi, "](url)", Markoff::Origin::Local);
        m_document->applyFlatEdit(byteLo, byteLo, "[",      Markoff::Origin::Local);
    }
    // Multi-block: same routine per block (skip non-text-bearing kinds).
    // (For E2.5 plan brevity, multi-block delegates to wrapPerBlock with
    //  open="[" and close="](url)" — the path is symmetric to bold/italic.)
}

}  // namespace Markoff::Live

            b.append(QByteArray::number(i));
