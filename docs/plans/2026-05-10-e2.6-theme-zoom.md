# E2.6 — Theme wire-up + zoom — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Route every text-bearing element in `markoff-live` through `Markoff::Theme`, add a per-binding `fontScale` for Ctrl+= / Ctrl+- / Ctrl+0 / Ctrl+wheel zoom, and wire a light/dark toggle action.

**Architecture:** `Theme` gains `pixelSizeFor(Slot)` + `familyFor(Slot)` convenience getters; `LiveListModelBinding` gains a clamped `fontScale` Q_PROPERTY; `LiveActionController` gains zoom + theme-toggle QActions; the theme-toggle action emits a signal the host catches to apply `defaultLight()`/`defaultDark()`. Each delegate replaces hardcoded `font.*` with `theme.pixelSizeFor(slot) * binding.fontScale` + `theme.familyFor(slot)` + `theme.isBold(slot)` + `theme.isItalic(slot)`. Inline-code spans propagate `fontScale` through `InlineHighlighterAttached` so they zoom with the document.

**Tech Stack:** C++20, Qt 6.8+, CMake 3.19+, QML, existing `markoff-core` and `markoff-live` test harnesses.

**Spec:** `docs/specs/2026-05-10-e2.6-theme-zoom-design.md`. Read all 11 sections before starting.

```cpp
namespace {
Markoff::Theme::FontRole roleFor(Markoff::Theme::Slot s) {
    using S = Markoff::Theme::Slot;
    using R = Markoff::Theme::FontRole;
    switch (s) {
        case S::Heading1: case S::Heading2: case S::Heading3:
        case S::Heading4: case S::Heading5: case S::Heading6:
            return R::Heading;
        case S::CodeBlock: case S::InlineCode: case S::Math:
            return R::Monospace;
        default:
            return R::Body;
    }
}
}  // namespace
```

Then add the method bodies inside `namespace Markoff` (e.g., after `setFontSizeMultiplier`):

```cpp
qreal Theme::pixelSizeFor(Slot s) const
{
    QFont f = font(roleFor(s));
    qreal pt = f.pointSizeF() > 0 ? f.pointSizeF() : 11.0;
    qreal mul = fontSizeMultiplier(s);
    if (mul <= 0) mul = 1.0;
    return pt * mul * (96.0 / 72.0);
}

QString Theme::familyFor(Slot s) const
{
    return font(roleFor(s)).family();
}
```

### Task 6A: Self-wire `setBinding` + add `applyDefaultTheme` Q_INVOKABLE

**Why this lives in the binding, not the app.** The test app `markoff-live-app` constructs the `LiveListModelBinding` declaratively in `Main.qml`. The binding's pimpl constructor wires its own sub-controllers (selection view, clipboard, format) into the action controller. Following that pattern, `setBinding(this)` belongs in the same place. For the theme toggle, the host triggers via signal and the binding owns the application — so we add a `Q_INVOKABLE applyDefaultTheme(bool dark)` convenience that QML can call directly. This avoids exposing `Theme::defaultLight()`/`defaultDark()` static factories to QML (Q_GADGET makes that awkward).

**Files:**
