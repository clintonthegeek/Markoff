# Appendix B: GitHub Repos and External Resources

Agent report: GitHub repositories, vaults, and web resources for understanding Obsidian's editor UX.

---

## TIER 1 — HIGHEST PRIORITY (Cloned)

### 1. obsidianmd/obsidian-help — 1,645 stars
- https://github.com/obsidianmd/obsidian-help
- **The official Obsidian help documentation vault.** Published at https://help.obsidian.md
- Contains:
  - `en/Editing and formatting/` — Basic formatting, Advanced formatting, OFM, Callouts, Properties, Tags, Multiple cursors, Editing shortcuts, Folding, Views and editing mode, HTML content, Embed web pages
  - `en/User interface/` — Tabs, Workspace, Sidebar, Hotkeys, Drag and drop, Appearance, Pop-out windows, Ribbon, Status bar
  - `en/Plugins/` — All core plugin docs (Canvas, Search, Graph view, Backlinks, Bookmarks, Outline, etc.)
  - `en/Linking notes and files/` — Internal links, Aliases, Embed files
  - `Sandbox/` — Built-in sandbox vault with formatting examples for every element
  - `en/Live preview update.md` — How Live Preview works
- **Cloned to:** `testvaults/obsidian-help/`

### 2. kepano/obsidian-skills — 18,639 stars
- https://github.com/kepano/obsidian-skills
- By Steph Ango (Obsidian CEO). Machine-readable specification of Obsidian's markdown syntax.
- Contains:
  - `skills/obsidian-markdown/SKILL.md` — Complete Obsidian Flavored Markdown reference
  - `skills/obsidian-markdown/references/CALLOUTS.md` — Callout types and syntax
  - `skills/obsidian-markdown/references/EMBEDS.md` — Embed/transclusion syntax
  - `skills/obsidian-markdown/references/PROPERTIES.md` — YAML frontmatter property types
  - `skills/json-canvas/` — JSON Canvas format specification
  - `skills/obsidian-bases/` — Obsidian Bases (database views) spec
  - `skills/obsidian-cli/` — CLI interaction spec
- **Cloned to:** `testvaults/obsidian-skills/`

### 3. obsidianmd/jsoncanvas — 3,338 stars
- https://github.com/obsidianmd/jsoncanvas
- Homepage: https://jsoncanvas.org
- Official open specification for the `.canvas` file format.
- **Cloned to:** `testvaults/jsoncanvas/`

### 4. obsidianmd/obsidian-developer-docs — 421 stars
- https://github.com/obsidianmd/obsidian-developer-docs
- Official developer documentation for building Obsidian plugins and themes.
- Contains CSS variable references, API documentation, and plugin architecture.
- **Cloned to:** `testvaults/obsidian-developer-docs/`

### 5. obsidian-community/obsidian-hub — 965 stars
- https://github.com/obsidian-community/obsidian-hub
- Published at https://publish.obsidian.md/hub
- Community-maintained vault with guides, workflows, plugin/theme cataloging.
- **Already present as:** `testvaults/obsidian-hub-main/`
